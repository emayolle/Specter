for the sake of the argument, and for the context of mod menus, if its detected it simply doesn't work
In the context of software and anti-cheat systems, "detected" and "not working" mean two completely different things:

Detected: This simply means that the anti-cheat system or security software has identified the signature, process, or behavior of the cheat. The system now knows that the software is active or was used.

Not Working: This means the software fails technically (for example, due to a game update, incorrect memory addresses, or a crash), meaning the desired modifications never actually execute in the game.

A cheat can work perfectly (executing all features like modifications or God mode) while simultaneously being fully detected. This often results in the game or anti-cheat system logging the event in the background, leading to a ban shortly afterward, even though the cheat was performing its technical function flawlessly at the time.
